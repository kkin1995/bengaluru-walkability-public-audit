## Citizen Footer Placement

| Option | Description | Selected |
|--------|-------------|----------|
| Non-map pages only | Conditional in root layout: show on /, /report, /success but skip /map. One SiteFooter component, one pathname check. | ✓ |
| All pages (root layout) | Footer appears everywhere including /map. Simple but full-screen Leaflet map page gets a footer it doesn't need. | |
| Per-page explicit | Import footer individually into each citizen page. Most control, but 3+ file repetition. | |

**User's choice:** Non-map pages only (Recommended)
**Notes:** The /map page has fixed-position floating controls (Report CTA, back button, filter strip) that would conflict with a page-bottom footer.

---

## Footer Visual Design

| Option | Description | Selected |
|--------|-------------|----------|
| Thin full-width bar | Full-width bar at page bottom: project name + version in --font-mono, --muted color, small font. Mirrors the admin sidebar brand mark aesthetic. | ✓ |
| Ultra-minimal inline text | Small text line at end of each page's content, no bar/border. Nearly invisible — version is there but unobtrusive. | |
| Floating corner label | Fixed bottom-right label, always visible. Modern PWA pattern but risks overlapping buttons on mobile. | |

**User's choice:** Thin full-width bar (Recommended)
**Notes:** Chosen for professional presentation (GBA handoff context) and consistency with admin sidebar brand mark pattern.

---

## Version String Format

| Option | Description | Selected |
|--------|-------------|----------|
| Brand + semver: Namma Daari · v0.1.0 | Shows project brand + version. Consistent with the admin sidebar pattern (WLK.CONSOLE / BENGALURU). Env var holds semver, surfaces add brand prefix. | ✓ |
| Bare semver: v0.1.0 | Just the version number. Clean and minimal. | |
| Semver + env tag: v0.1.0 (staging) | Adds the environment. Useful during GBA pilot. Requires a second env var. | |

**User's choice:** Brand + semver: Namma Daari · v0.1.0 (Recommended)
**Notes:** Matches the admin sidebar treatment. Admin shows `BENGALURU · v{version}`, citizen shows `Namma Daari · v{version}`.
