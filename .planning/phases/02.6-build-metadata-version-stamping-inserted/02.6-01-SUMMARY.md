### Task 2: Create SiteFooter + FooterBoundary; mount in root layout

**Commit:** 6208864

Created `frontend/app/components/SiteFooter.tsx` as a Server Component (no `"use client"`) rendering `Namma Daari · v{APP_VERSION}` with inline CSS var tokens (`var(--font-mono)`, `var(--muted)`, `var(--border)`, `var(--bg)`) and `max(8px, env(safe-area-inset-bottom))` padding for iOS notch. ## Decisions Made

1. **FooterBoundary Option A chosen** — Client boundary wrapper (`usePathname` in `FooterBoundary.tsx`) preserves root layout as Server Component with zero file moves. Option B (route group restructure) was discarded.
2. **`APP_VERSION` fallback `"0.0.0"`** — For local dev or Jest environments where Next.js build-time injection has not run.
3. **No className in SiteFooter** — All typography and color applied via `style={{ }}` objects with CSS custom property tokens per Phase 02.3.1 design system convention (D-05).
