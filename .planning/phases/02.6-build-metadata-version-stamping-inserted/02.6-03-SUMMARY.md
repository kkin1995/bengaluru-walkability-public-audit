## Summary

Gap closure plan for Phase 02.6 UAT gaps 1 and 2. Two confirmed major-severity issues fixed with surgical edits across four files. Build and lint pass clean.

## What Was Built

### Task 1: Sticky-footer layout (Gap 1 — footer whitespace on /report)

**Root cause:** Each step container in `report/page.tsx` set `minHeight: "100dvh"`, making total document height = `100dvh + footer height`, pushing the SiteFooter below the viewport.

**Fix:**
- `frontend/app/layout.tsx`: Body className extended from `min-h-screen antialiased` to `min-h-screen antialiased flex flex-col`; children wrapped in `<div className="flex-1">` before `<FooterBoundary />`. The flex column distributes space correctly: children expand to fill available height, footer sticks to the bottom.
- `frontend/app/report/page.tsx`: Removed `minHeight: "100dvh"` from all four step `<main>` containers (success render at line 408, photo step at line 434, category step at line 569, confirm step at line 764).

**Preserved (out of scope):**
- `frontend/app/page.tsx` home `<main minHeight: "100dvh">` — UAT did not flag any issue on `/`
- `frontend/app/map/page.tsx` `height: "100dvh"` — FooterBoundary returns null on /map, no collision
- `minHeight: 128` CategoryGrid card in `report/page.tsx` — not a step container

### Task 2: Admin logout hard navigation (Gap 2 — soft navigation on logout)

**Root cause:** Both logout handlers used `router.push("/admin/login")` (Next.js soft navigation), which keeps the admin shell (sidebar + layout) mounted. The login form rendered inside the shell's content slot instead of as a full-page view.

**Fix:**
- `frontend/app/admin/components/AdminSidebar.tsx`: Replaced `router.push("/admin/login")` with `window.location.replace("/admin/login")` in `handleLogout`. Removed now-unused `const router = useRouter()` declaration and dropped `useRouter` from the `next/navigation` import. `usePathname` retained (still in use).
- `frontend/app/admin/profile/page.tsx`: Replaced `routerRef.current.push("/admin/login")` with `window.location.replace("/admin/login")` in `handleLogout` (line 166 only).

**Preserved (out of scope):**
- Lines 63 and 95 in `profile/page.tsx` — auth-failure (401) redirects from `loadProfile` and `handleSaveProfile` remain as `routerRef.current.push` soft navigation (not user-triggered logouts)
- `useRouter`, `routerRef` fully remain in `profile/page.tsx` (used at lines 17, 18, 63, 95)
