<objective>
Close the two confirmed major-severity UAT gaps from 02.6-UAT.md:

1. **Footer whitespace on /report (test 1, severity: major):** The SiteFooter rendered by FooterBoundary in the root layout is being pushed below the viewport because every step container in `frontend/app/report/page.tsx` sets `minHeight: "100dvh"`, so total document height = `100dvh + footer height` > viewport. Fix by converting `<body>` to a flex-col sticky-footer pattern (children in a `flex-1` wrapper, FooterBoundary as the sticky sibling) and removing the four `minHeight: "100dvh"` declarations on the step containers.

2. **Admin logout soft navigation (test 4, severity: major):** `AdminSidebar.tsx:79` and `profile/page.tsx:166` use Next.js `router.push("/admin/login")` (soft navigation) for the post-logout redirect. Soft navigation keeps the admin shell (sidebar + layout) mounted, so the login form renders inside the shell's content slot instead of as a full-page view. The user sees the sidebar persist after logout. Fix by replacing both call sites with `window.location.replace("/admin/login")` for a hard navigation that fully unmounts the admin layout.

**Scope discipline:**
- Only the THREE step containers in report/page.tsx and the SUCCESS render branch (4 occurrences of `minHeight: "100dvh"` at lines 408, 434, 569, 764) are touched. The CategoryGrid card's `minHeight: 128` at line 483 is NOT a step container and stays.
- Only the TWO user-triggered logout call sites are changed. The TWO auth-failure (401) redirects in profile/page.tsx at lines 63 and 95 remain as `routerRef.current.push(...)` — they are not logout actions; they redirect from a failed authenticated request. Per UAT root_cause, only line 166 is in scope.
- `frontend/app/page.tsx` (home) has `minHeight: "100dvh"` at line 47 but the UAT did NOT flag any footer issue on `/` — test 1 reported the issue specifically on `/report`. Leave home page unchanged; the sticky-footer layout in body covers the home page automatically because flex-1 expands the home `<main>` to fill the viewport minus the footer.
- After replacing `router.push` in AdminSidebar.tsx, the `const router = useRouter()` declaration at line 73 and the `useRouter` import at line 4 become unused. Remove both to avoid ESLint `no-unused-vars` regressions. `usePathname` (also imported on line 4) is still used and must be retained.

Purpose: Restore the SiteFooter to visible-without-scroll on /report (VERSION-01 user-visible requirement) and make the admin logout flow render the standalone login page (admin shell unmounts).
