<objective>
Implement NF-03-B: automatically assign the matching BBMP corporation organization to a report at creation time based on the ward's geographic territory, record a system audit trail entry, and make the admin reports list CORP column show the assigned organization name instead of the raw ward geography string.

Purpose: Closes the confirmed Phase 3 UAT gap NF-03-B (major). GBA admins currently see "Central" in the CORP column and no automatic routing happens — reports are unrouted until manual assignment. Auto-assignment removes a manual triage step and the CORP column becomes meaningful.
Output: A new get_org_for_ward query, a modified insert_report that persists assigned_org_id, a best-effort status_history audit insert in create_report, a corrected list_admin_reports CORP column, and SQL-string unit tests for all three behaviors.
</objective>
