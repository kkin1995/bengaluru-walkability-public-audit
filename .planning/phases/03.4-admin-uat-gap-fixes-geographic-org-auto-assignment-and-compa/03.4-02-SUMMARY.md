# Phase 03.4 Plan 02: CompactRow Full-Card Navigation Summary

**One-liner:** CompactRow outer div made tappable via window.location.assign + sr-only anchor (DupeSubTable pattern), with stopPropagation on Status and Delete buttons to prevent nav collision.

## What Was Built

NF-03-A closed: the entire mobile compact-row report card body now navigates to `/admin/reports/:id` on tap. Previously only the WLK-XXXXX chip was tappable. This brings the compact-rows view in line with the desktop table and the dupe sub-table.

### Changes to `frontend/app/admin/components/ReportsTable.tsx`

1. **CompactRow outer `<div>`** — added `cursor: "pointer"` to inline style and `onClick={() => window.location.assign(`/admin/reports/${report.id}`)}`.
2. **sr-only anchor** — added `<a href={`/admin/reports/${report.id}`} className="sr-only">View report {report.id.slice(0, 5).toUpperCase()}</a>` as first child of the outer div (DupeSubTable pattern).
3. **Status Btn onClick** — changed from `onClick={() => (onUpdateStatus ?? onStatusChange)(report.id)}` to `onClick={(e) => { e.stopPropagation(); (onUpdateStatus ?? onStatusChange)(report.id); }}`.
4. **Delete Btn onClick** — changed from `onClick={() => onDelete(report.id)}` to `onClick={(e) => { e.stopPropagation(); onDelete(report.id); }}`.

### Changes to `frontend/app/admin/components/__tests__/ReportsTable.test.tsx`

Added `describe("CompactRow: full-card navigation")` with one `it` block that:
1. Renders ReportsTable with REPORT_A in default (card-stream) mode
2. Clicks the ROWS button to switch to compact-rows mode (JSDOM defaults to card-stream since `window.matchMedia` is unavailable)
3. Asserts `screen.getByRole("link", { name: /view report/i })` has `href` equal to `/admin/reports/${REPORT_A.id}`

### Adjustments

**[Rule 1 - Bug] Test updated to click ROWS button before asserting sr-only anchor**
- **Found during:** Task 1 GREEN phase
- **Issue:** JSDOM does not implement `window.matchMedia`, so ReportsTable defaults to `card-stream` mode (not `compact-rows`). The plan's test snippet assumed compact-rows would be active. The sr-only anchor only exists in `CompactRow`, which only renders when viewMode is `compact-rows`.
- **Fix:** Added `await userEvent.click(screen.getByRole("button", { name: /rows/i }))` before asserting the link. This switches to compact-rows mode within the test, matching the mobile scenario the plan targets.
