a cluster of pixel values that are close in size but serve the same visual hierarchy level.
These intra-tier variations are implementation details from the finalized asset — they are not
separate visual hierarchy levels and are not listed as additional scale entries.

| Body | `clamp(15px, 1.9vw, 18px)` | 400 | 1.62 | `var(--font-sans)` | Description paragraph — `color: var(--ink-2)`; `text-wrap: pretty`; `max-width: 600px` |

## Component Mapping

### Wordmark

- **Pattern:** Inline `<span>` elements with `.en` and `.kn` classes, wrapped in `.wordmark`.
- **Do NOT use `<Bi>` here.** The design renders EN and KN on the same baseline (inline-flex, `align-items: baseline`) — not as stacked column text. `<Bi>` renders flex-column, which would stack them vertically. Use the inline pattern from the design HTML directly.

```tsx
<div className="wordmark">
  <span className="en">Namma Daari</span>
  <span className="kn">ನಮ್ಮ ದಾರಿ</span>
</div>
```

CSS for `.wordmark`, `.en`, `.kn` must be added as scoped styles or a CSS module —
do NOT add to `globals.css` (global namespace).

### Tagline Kannada

- **Pattern:** Plain `<p>` with `className="tagline-kn"` containing inline `<span className="translit">`.
- **Do NOT use `<Bi>` here.** The design renders the Kannada text and the transliteration inline on one row.

### Instagram CTA button

- **Pattern:** `<a href="https://instagram.com/nammadaariblr" target="_blank" rel="noopener" className="ig-btn press">`.
- **Do NOT use `<Btn>` here.** `<Btn>` renders a `<button>` element and does not accept `href`. The CTA is a navigation anchor. Use the `.ig-btn` CSS class with `press` interaction class from `globals.css`.
- The `.ig-btn` styles must be added as scoped styles or a CSS module — do NOT add to `globals.css`.
- The Instagram SVG icon is inline (20×20, `viewBox="0 0 24 24"`, `aria-hidden="true"`).

### Status chip

- **Pattern:** Plain `<div className="status-chip">` with a `<span className="dot pulse">` inside.
- The `.pulse` class from `globals.css` provides the breathing animation.
- Text: `Coming soon · Bengaluru`.

### SectionLabel

- **Not used in the coming soon page.** The design uses `.eyebrow` instead, which is an independent typographic pattern. `<SectionLabel>` is present in the current `page.tsx` (citizen home page) but is not part of the coming soon design.

### Bi component

- **Not used in the coming soon page.** The design does not use stacked bilingual columns. See Wordmark note above.

## Interaction Contract

| Interaction | Behaviour |
|-------------|-----------|
| Instagram CTA tap / click | Navigates to `https://instagram.com/nammadaariblr` in a new tab (`target="_blank"`, `rel="noopener"`) |

| Status dot | `.pulse` CSS animation: opacity + scale breathe, 2s ease-in-out infinite, only when `prefers-reduced-motion: no-preference` |
| Hover states | No explicit hover states declared in design. Native link underline suppressed via `text-decoration: none` on `.ig-btn`. |
| Focus / keyboard | Standard browser focus ring on the `<a>` anchor. No custom focus override — do not suppress. |
| Page scroll | Single-screen composition on desktop. No scroll interactions required. Mobile may scroll on very small viewports — no special handling needed. |

## Implementation Notes

1. **CSS scoping:** All page-specific CSS classes (`.page`, `.topbar`, `.wordmark`, `.en`, `.kn`,
   `.status-chip`, `.dot`, `.hero`, `.eyebrow`, `.tagline`, `.tagline-kn`, `.translit`, `.desc`,
   `.cta-row`, `.ig-btn`, `.handle`, `.cta-note`, `.footer`, `.tags`, `.tag`) must be scoped to
   this page — use a CSS Module (`coming-soon.module.css`) or inline styles. Do not pollute
   `globals.css` with coming-soon-only rules.

2. **Reuse from `globals.css`:** The following classes are already global and should be referenced
   directly without re-declaring: `.press`, `.pulse`, `.kn`, `.mono`.

3. **This is a Server Component.** No `"use client"` directive. No hooks. No API calls.
   Plain synchronous render.

4. **No layout wrapper.** The current `layout.tsx` applies global `<body>` font/color. The coming
   soon page manages its own flex layout within `<body>` directly — no shared nav, footer, or
   sidebar from the citizen app.

5. **Flip mechanism** (D-26): When `/gsd-complete-milestone` merges `staging` into `main`, the
   full citizen `page.tsx` from staging overwrites this file. No additional code is needed to
   remove the coming soon page.
