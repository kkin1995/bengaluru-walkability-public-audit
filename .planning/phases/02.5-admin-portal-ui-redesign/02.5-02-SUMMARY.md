# Phase 02.5 Plan 02: Component Rewrite (AdminSidebar, Login, Dashboard, StatsCards) Summary

AdminSidebar with desktop sidebar (220px) + mobile bottom tab bar + dark mode toggle, login page with Direction B terminal aesthetic + SEC-06 locked error strings, and dashboard with offline indicator + responsive mobile/desktop layout — all using Plan 01 CSS custom property token layer with zero Tailwind.

## What Was Built

### Task 1: AdminSidebar + Login Page

**AdminSidebar.tsx** — full rewrite replacing lucide-react slide-in drawer:
- Desktop sidebar (220px fixed left): brand mark, 7 nav items with role gates (USERS + ORGS require admin/super_admin), spacer, QUICK CMD Kbd hint
- Mobile bottom tab bar (4 tabs: OPS, QUEUE, MAP, USERS), `position: fixed; bottom: 0`
- Active state via `usePathname()` — exact match for `/admin`, prefix match for sub-paths
- Dark mode toggle: `aria-label="Toggle dark mode"`, reads/writes `localStorage.admin-theme`, toggles `.dark` on `document.documentElement`
- Initial dark state read inside `useEffect` to avoid SSR hydration mismatch
- Responsive switching: `matchMedia("(min-width: 768px)")` + useEffect + useState
- Zero Tailwind, zero lucide-react — Icon, Avatar, Btn, Kbd primitives from Plan 01

**login/page.tsx** — Direction B terminal aesthetic:
- ASCII banner (`<pre aria-hidden="true">`), `$ login` headline, security hint row
- Input primitives (`icon="mail"`, `icon="lock"`), Btn `variant="accent"` "AUTHENTICATE"
- Error region: `role="status" aria-live="polite"`, warn-tone CSS vars

**SEC-06 error string mapping:**

| HTTP Status | Error String |
|-------------|--------------|
| 401 | "Incorrect email or password." |
| 429 | "Too many attempts. Please wait a few minutes before trying again." |
| all other + network | "Something went wrong. Please try again." |

Raw server response body NEVER displayed. All error strings are locked constants.

**login-page.test.tsx** — updated to match new:
- Button pattern `{ name: /authenticate|sign in|log in|submit/i }`
- `role="status"` instead of `role="alert"` for error region
- T6/T8/T11 assertions updated to SEC-06 generic strings
- 38/38 tests pass

### Task 2: Dashboard + StatsCards + Test Update

**StatsCards.tsx** — CSS vars + primitives rewrite:
- Card primitive wraps each metric; SectionLabel for card label
- Loading skeletons: `data-testid="skeleton"`, `animation: "pulse 1.5s ease-in-out infinite"`, surface-2 background
- Error state: Pill `tone="danger"` + Btn `variant="ghost"` with `data-testid="stats-retry-button"`
- Grid: `gridTemplateColumns: "repeat(auto-fill, minmax(180px, 1fr))"` — no Tailwind media queries
- All data-testids preserved: `stats-cards`, `stats-cards-loading`, `stats-cards-error`, `stat-total`, `stat-submitted`, `stat-under-review`, `stat-resolved`, `skeleton`, `stats-retry-button`
- Dual prop shape preserved (data/loading and stats/isLoading/isError/onRetry)

**page.tsx (Dashboard)** — responsive with useOnlineStatus:
- `useOnlineStatus()` imported; offline banner: `role="status" aria-live="polite"`, warn-token styling, exact UI-SPEC strings
- Mobile layout: sync state bar, hero open-reports card (accent-bg, `var(--text-hero-mobile)` count), 2×2 StatsCards, severity composition (`role="list" aria-label="Open reports by severity"`), activity feed with `getCategoryLabel()`
- Desktop layout: 4-col hero row (inverted ink card + 3 metrics), 14-day Sparkbars with period Pill toggle chips, two-col severity + activity split
- Responsive switching: `matchMedia("(min-width: 1024px)")` with guard for environments where matchMedia is unavailable
- Zero Tailwind, zero lucide-react

**StatsCards.test.tsx** — Tailwind assertions removed:
- Replaced `document.querySelectorAll(".animate-pulse, .skeleton, ...")` with `document.querySelectorAll('[data-testid*="skeleton"]')`
- Replaced `\b0\b` regex zero check (fails on concatenated textContent) with per-testid `.textContent === "0"` assertions
- 5 uses of `data-testid` assertions preserved

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Guard] matchMedia guard for test environment**
- **Found during:** Task 2 dashboard test run
- **Issue:** `window.matchMedia` is not a function in jsdom — 19 dashboard tests threw TypeError on mount
- **Fix:** Added `typeof window.matchMedia !== "function"` guard before calling matchMedia in the responsive useEffect
- **Files modified:** `frontend/app/admin/page.tsx`
- **Commit:** 760e7ea (included in Task 2 commit)

**2. [Rule 1 - Bug] StatsCards zero-value regex test fix**
- **Found during:** Task 2 StatsCards test run
- **Issue:** `\b0\b` word boundary regex in the existing zero-check test returns 0 matches when textContent is `Total Reports0Submitted0...` — digits are `\w` chars so no word boundary exists between a letter and a digit
- **Fix:** Replaced regex test with per-testid assertion using `screen.getByTestId("stat-*").textContent === "0"` — semantically equivalent, more precise
- **Files modified:** `frontend/app/admin/components/__tests__/StatsCards.test.tsx`
- **Commit:** 760e7ea (included in Task 2 commit)
