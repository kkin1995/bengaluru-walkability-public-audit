### Task 2: Reports list page and Report detail page rewrites

#### `reports/page.tsx`

- **QUEUE heading**: `<h1>` with JetBrains Mono uppercase "QUEUE" + total count `<Pill tone="neutral" size="sm">`
- **Offline banner**: `useOnlineStatus()` + exact UI-SPEC strings: heading `"You're offline right now"`, body with apostrophes via `eslint-disable` comment (literal chars required for grep test)
- **Error state**: exact string `"Could not load reports. Check your connection and try again."` inside a Card with retry Btn
- **ReportsTable wiring**: passes `totalCount`, `page`, `totalPages`, `onPageChange` — ReportsTable owns view-mode toggling
- **Status-change modal**: inline Card (no Tailwind) with select + Cancel/Confirm buttons
- **Page wrapper**: `padding: "24px 32px", maxWidth: 1400`
- **Zero Tailwind; zero lucide-react**

#### `reports/[id]/page.tsx`

Mobile layout (default, `isDesktop = false` in tests):
- Photo area (280px height) with absolute overlays: 1 PHOTO chip (outline), EXIF_OK chip (accent, when location_source=exif), SHA chip (neutral, first 5 chars of UUID), zoom button with `aria-label="Zoom photo"`
- Status badges row: `<StatusBadge>` + `<SeverityIndicator>` + `<ConfidencePill>` + DUP count Pill
- Category title: `getCategoryLabel(report.category).en` (Inter 14px weight 600)
- Telemetry block (2-col grid, dashed row separators): LAT / LNG / WARD / LOCATION_SRC / SUBMITTED_AT / CATEGORY (raw slug) / DUP_CONF / UUID
- Action buttons 2-col grid: "Move to review" (accent, minHeight 44px) + "Mark resolved" (secondary, minHeight 44px)
- Citizen description Card: `SectionLabel "CITIZEN_DESCRIPTION"` + Inter 14px body text
- Map placeholder: 140px gradient tile + ward chip + coordinates + `<a href="...google.com/maps..." target="_blank" rel="noopener noreferrer">Open in Maps ↗</a>`
- Status timeline Card: `SectionLabel "STATUS_HISTORY · TAIL"` + current status as fallback entry (API doesn't expose history array)

Desktop layout (`isDesktop = true`):
- Split panel `gridTemplateColumns: "1.3fr 1fr"` — left: full-height photo; right: scrollable detail content
- Desktop top action bar: "View public" (ghost) + "Delete" (danger-soft, role-gated) + "Resolve" (accent), all minHeight 40px
- Back button inline with top bar

Delete confirmation modal:
- Backdrop `rgba(10,10,10,0.5)`, 480px Card, exact string `"Delete this report? This cannot be undone."`
- Cancel (ghost) + Delete (danger) buttons
- No `window.confirm()`

Error/404 handling:
- 404: exact string `"This report no longer exists or was removed."`
- Generic error: "Report not found" or API error message
- Both use `data-testid="report-detail-error"`

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed ReportsTable ward display breaking WARD-01 tests**
- **Found during:** Task 1 test run
- **Issue:** Previous partial commit `1cfa5ee` merged ward_name and location_source in a single text node (`"Shivajinagar · EXIF"`); `screen.getByText("Shivajinagar")` uses exact match and failed
- **Fix:** Split into separate `<span>` elements; added "Ward" label span for column header assertion
- **Files modified:** `frontend/app/admin/components/ReportsTable.tsx`
- **Commit:** `ba4e579`

**2. [Rule 1 - Bug] Fixed getMe() null guard in [id]/page.tsx**
- **Found during:** Task 2 test run
- **Issue:** `jest.fn()` returns `undefined`; calling `.then()` on `undefined` throws TypeError
- **Fix:** Added `if (promise && typeof promise.then === "function")` guard
- **Files modified:** `frontend/app/admin/reports/[id]/page.tsx`
- **Commit:** `ba4e579`

**3. [Rule 1 - Bug] Fixed formatDate to match test expected format**
- **Found during:** Task 2 test run
- **Issue:** `toLocaleDateString("en-IN", {...options})` adds time; test expects plain `toLocaleDateString()` date-only format
- **Fix:** Simplified to `new Date(isoString).toLocaleDateString()` without options
- **Files modified:** `frontend/app/admin/reports/[id]/page.tsx`
- **Commit:** `ba4e579`

**4. [Rule 1 - Bug] "No description" text mismatch**
- **Found during:** Task 2 test run
- **Issue:** Rendered `"No description provided."` (with period); test expects `"No description"`
- **Fix:** Removed period
- **Files modified:** `frontend/app/admin/reports/[id]/page.tsx`
- **Commit:** `ba4e579`
