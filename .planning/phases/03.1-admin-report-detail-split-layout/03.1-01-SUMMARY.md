## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Keep `identityStripContent`/`actionRailContent` as inline JSX vars in `page.tsx` | Per RESEARCH.md Open Question #3: single-use 40-line sections don't justify new component files; reduces cognitive overhead |
| Add `data-status-token` attribute to timeline dot span | JSDOM drops `background: var(--*)` from inline styles (cannot resolve CSS custom properties); `data-status-token` makes the token choice testable without runtime CSS resolution |
| Use `getAllByText` in ISSUE-01/ISSUE-03 tests where ward_name = assembly_constituency | "Shivajinagar" appears in both the Ward chain row and the assembly constituency span after ISSUE-04 split — `getByText` fails with "multiple elements found" |
| Left column identity strip has `overflowY: "auto"` with `maxHeight: "40%"` | Allows the identity strip to scroll internally if telemetry grid overflows narrow viewports while keeping the outer left column non-scrolling |

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] JSDOM drops CSS variable background from inline style**
- **Found during:** Task 1 RED / Task 2 GREEN (ISSUE-06 test)
- **Issue:** JSDOM serializes `background: "var(--status-open)"` by dropping the property entirely (JSDOM cannot resolve CSS custom properties). The test approach from PATTERNS.md (checking `el.getAttribute("style")`) found an empty string instead of the token name.
- **Fix:** Added `data-status-token={...}` data attribute to the timeline dot `<span>` in `page.tsx`. Test updated to assert `querySelector('[data-status-token]').getAttribute("data-status-token")` contains the expected token string.
- **Files modified:** `page.tsx`, `page.test.tsx`
- **Commit:** 1865003

**2. [Rule 1 - Bug] `getByText` finds multiple elements with shared text in ISSUE-01/ISSUE-03 tests**
- **Found during:** Task 2 GREEN (test run)
- **Issue:** After ISSUE-04 fix splits AC label into two spans, "Shivajinagar" appears in both the Ward chain row ("117 · Shivajinagar") and the assembly constituency span ("Shivajinagar"). `getByText("Shivajinagar")` and `getByText(/Shivajinagar/)` fail with "Found multiple elements".
- **Fix:** Updated ISSUE-01 and ISSUE-03 Ward-row tests to use `getAllByText` with `.length >= 1` assertion.
- **Files modified:** `GbaHierarchyPanel.test.tsx`
- **Commit:** 1865003
