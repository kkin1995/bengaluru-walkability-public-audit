## Decisions Made
- Self-hosted runner labeled `[self-hosted, linux, walkability-prod]` — three-label match ensures only the walkability desktop runner picks up the deploy job, not any other self-hosted runner that may be registered to the account
- `COOKIE_SECURE: "true"` hard-coded in the workflow (not from a secret/var) — Cloudflare terminates TLS for all traffic so the value is always true in production; no environment-specific override needed
- Job-level `env:` block on the deploy job rather than per-step env — all four steps inherit the same secrets, avoiding repetition and reducing misconfiguration risk
- `smoke-test` runs on `ubuntu-latest` (GitHub-hosted) rather than self-hosted — tests public Cloudflare tunnel reachability from outside the local network, providing genuine end-to-end validation
- All secrets mandatory (no `if: secrets.X != ''` gating) — if any secret is missing the deploy fails fast with a clear error rather than silently deploying a misconfigured service
- `production` environment gate on the deploy job — allows GitHub Environment protection rules (required reviewers, deployment branches) to govern when deploys execute

## User Setup Required
Before the deploy job can run, the following must be configured in GitHub repository settings:

**Secrets** (Settings > Secrets and variables > Actions > Secrets):
- `POSTGRES_PASSWORD` — postgres container password
- `JWT_SECRET` — backend signing key (`openssl rand -hex 32`)
- `ADMIN_SEED_EMAIL` — initial super-admin email
- `ADMIN_SEED_PASSWORD` — initial super-admin password (min 12 chars)

**Variables** (Settings > Secrets and variables > Actions > Variables):
- `BACKEND_URL` — public Cloudflare tunnel URL (e.g., `https://api-walkability.kinariwala.com`)
- `FRONTEND_URL` — Vercel frontend URL (e.g., `https://staging-walkability.kinariwala.com`)
- `CORS_ORIGIN` — exact origin string (matches FRONTEND_URL, no trailing slash)

**Environment** (Settings > Environments):
- Create `production` environment; configure required reviewers as desired

**Self-hosted runner** (plan 03):
- Must be installed on Arch Linux desktop with labels: `self-hosted`, `linux`, `walkability-prod`
- Runner user must be in the `docker` group
