## Decisions Made

- WARD_LINK_MIGRATION_SQL const mirrors the migration file SQL so that the test-only `ward_link_migration_sql_fragment()` hook can assert pattern correctness without running the migration against a live DB. A comment above the const documents the sync requirement.
- Used `WHERE wards.org_id IS NULL` for idempotency — already-linked wards are skipped on re-run. This is safer than an unconditional UPDATE.
- Confirmed the ILIKE pattern `'%' || wards.corporation || '%'` matches the one used in `get_org_for_ward` (queries.rs line 91). The test `ward_org_id_ilike_pattern_consistency` permanently guards this invariant.
