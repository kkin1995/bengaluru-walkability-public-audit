## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Information Disclosure | PUBLIC_GEOJSON_SQL | mitigate | Whitelist column selection (D-17), no submitter_name/contact/ip/photo_hash; coordinates rounded to 3dp (~111m) so exact locations are obscured |
| T-04-04 | Denial of Service | /api/reports.geojson | mitigate | Two-layer rate limiting per D-18: nginx geojson_public zone 2r/m burst 1 (primary) + governor 2/min keyed limiter (defense in depth) |
| T-04-05 | Denial of Service | streaming GeoJSON timeout | mitigate | nginx proxy_read_timeout 120s prevents premature cutoff; streaming avoids buffering all rows in memory |
| T-04-06 | Tampering | public_stats_mv refresh trigger | accept | Trigger fires REFRESH CONCURRENTLY on statement; at MVP scale (<10k reports) refresh is <50ms — acceptable write overhead |
| T-04-SC | Tampering | npm/cargo installs | mitigate | No new packages in this plan (governor/tokio-util already present) — slopcheck N/A |
