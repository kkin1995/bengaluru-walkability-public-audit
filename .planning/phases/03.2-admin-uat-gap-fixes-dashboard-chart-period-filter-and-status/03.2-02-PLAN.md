<backend_contract priority="important">
Plan 03.2-01 extends GET /api/admin/reports/:id to return:
- `updated_at`: ISO-8601 string (now always present)
- `status_history`: array of objects, newest-first, each with:
    `id` (string), `old_status` (string | null), `new_status` (string),
    `changed_at` (ISO string), `note` (string | null),
    `changed_by` (string | null), `changed_by_name` (string | null)

`changed_by_name` is null (not "SYSTEM") when the change had no attributed admin
or the admin has no display_name. The frontend must handle null gracefully
(render "—" or omit the "by" clause), NEVER print the literal "SYSTEM".
</backend_contract>
