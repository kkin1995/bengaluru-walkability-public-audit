<objective>
Create the public, unauthenticated ward boundary GeoJSON endpoint for the public map overlay (TRIAGE-04, per D-14/D-22/D-23) and resolve the route conflict that blocks it.

Purpose: The existing `/api/wards/boundaries` endpoint is registered INSIDE admin_protected_router (auth-gated) — the public map cannot use it. This plan promotes a public version, renames the admin one to `/api/admin/wards/boundaries`, updates the admin choropleth caller, and adds nginx edge caching. Plan 05 (frontend overlay) depends on this endpoint existing.
Output: public `GET /api/wards/boundaries` (no auth), renamed admin `GET /api/admin/wards/boundaries`, updated `getWardBoundaries()` caller, nginx Cache-Control on both configs.
</objective>
