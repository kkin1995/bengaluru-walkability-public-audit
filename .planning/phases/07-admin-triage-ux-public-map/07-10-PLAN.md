<objective>
Fix two UAT failures that Plan 07-07 did not fully resolve:

1. MOB-01 + MOB-02 nav clearance (re-fix): Plan 07-07 used 56px as the bottom nav height per UI-SPEC. The actual rendered nav height is ~67px (padding: 8px top + 44px content + 14px bottom + 1px border). Without viewport-fit:cover in the page metadata, env(safe-area-inset-bottom) returns 0 on iOS Safari, so the total padding is only 56px. 11px of the last content box is hidden behind the 67px nav. Fix: increase admin-safe-bottom from 56px to 76px (67px nav + 9px visible buffer). Keep env(safe-area-inset-bottom) for devices where viewport-fit:cover is active.

2. MOB-02 compact rows layout: In compact-rows view, the CompactRow component uses flexWrap:wrap. On mobile widths (~375px), the severity badge, status badge, and action buttons wrap to a second line in an uncontrolled way, causing text overlap and cramped layout. Fix: restructure CompactRow to a deterministic 2-row layout: [Photo | Category + badges on right] then [ID·ward·time + action buttons on right]. No wrapping occurs because all items fit within their designated row.
</objective>
