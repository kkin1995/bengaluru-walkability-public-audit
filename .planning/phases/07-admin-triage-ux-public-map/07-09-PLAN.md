<objective>
Fix two UAT failures in TrendChart.tsx that Plan 07-07 did not fully resolve:

1. MOB-03 (re-fix): Chart renders blank on iOS Safari initial load — only a dot/tooltip appears on tap, no visible line data. Root cause: ResponsiveContainer with `height={300}` (numeric) uses ResizeObserver internally; on iOS Safari the observer fires before the SVG paint cycle, resulting in zero-height rendering. Fix: change to `height="100%"` (string) on ResponsiveContainer (parent wrapper already has `height: 300` in pixels, so "100%" fills it correctly). Also add `isAnimationActive={false}` to all Line elements — iOS Safari sometimes fails to complete Recharts' SVG stroke-dashoffset animation, leaving lines invisible.

2. MOB-04 (re-fix): Chart tooltip shows raw DB enum strings (e.g. "blocked_footpath : 2"). Plan 07-07 added a Legend formatter but left `<Tooltip />` bare. Fix: add a `formatter` prop to Tooltip that maps the key name via getCategoryLabel.

Both fixes are in a single file. No behavior, data, or API changes.
</objective>
