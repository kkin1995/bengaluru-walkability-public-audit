<objective>
Add backend support for the admin reports queue ward/corporation filter (TRIAGE-01, per D-03/D-04/D-05). This delivers two new admin-gated endpoints that supply filter options, plus ward_id/corporation_id filtering of the report list query.

Purpose: The admin reports queue UI (Plan 04) needs live corp/ward option lists and a backend that narrows results by geographic scope. This plan is the data tier; Plan 04 is the UI tier.
Output: `GET /api/admin/corporations`, `GET /api/admin/wards?corp_id=`, and ward_id/corporation_id filter params on the existing admin reports list + count queries, with regenerated SQLx offline metadata.
</objective>
