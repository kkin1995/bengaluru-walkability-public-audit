# Phase 02.3.1 Plan 02: Home Page and Map Page Redesign Summary

## What Was Built

### Task 1: Home Page (`/`) — TDD

Replaced the old Tailwind-gradient home page (green gradient, trust-pills, How it works section) with the Walkable BLR redesign from the design file.

**Structure:**
- Header: 28x28 dark square with white pin icon + "Namma ದಾರಿ" (Inter 700) + "Walkable BLR" (mono 10px) + language toggle display-only (EN · ಕ, globe icon, deferred functionality)

- Trust sub-copy: "No login · Takes 20 seconds · Anonymous" (14px, `var(--muted)`)

**Primitives used:** Bi, Btn, Icon, Pill, SectionLabel (all from Plan 01).

**TDD commits:**

### Task 2: Map Page (`/map`)

Replaced the old header+legend+ReportsMap layout with a full-bleed overlay design.

**Structure:**
- `"use client"` — required for `useState<string>("all")` filter chip state
- ReportsMap fills 100% via `position: absolute; inset: 0` — Leaflet still uses `nextDynamic(..., { ssr: false })` even inside a client component (Research Pitfall 5 confirmed working)
- Top overlay bar (zIndex 500): back arrow Link to `/` (44px circle) + Bengaluru location pill (flex 1, pill shape) + filter button (44px circle)
- Filter chip strip (zIndex 500, top: 76px): horizontal scroll `.no-scrollbar`, 6 chips (All/Damaged/Blocked/No path/Crossing/Lighting), active chip = `var(--ink)` fill
- Floating "Report here" CTA: `<Link href="/report"><Btn variant="accent" size="lg" style borderRadius="var(--r-full)">` bottom-right

**Removed:** `export const dynamic = 'force-dynamic'` (not needed for client component), old header with "All Reports" title, old color-dot legend strip.

**ReportsMap.tsx:** Untouched — confirmed via `git diff --name-only HEAD -- frontend/app/components/ReportsMap.tsx` (empty output).
