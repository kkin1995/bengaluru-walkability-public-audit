# Phase 02.3 Plan 01: Admin Category Labels and Map Legend Consistency Summary

**getCategoryLabel() from translations.ts unified across admin table, map legend, and map popup — eliminating raw enum display (BUG-01) and abbreviated legend labels (UX-03), with mobile scroll gradient added to admin table (UX-01)**

## Accomplishments

- Admin reports table now shows "Damaged Footpath" instead of "broken_footpath" in both the main table and the expandable sub-table (BUG-01)
- Mobile admin table has a right-edge fade gradient (pointer-events-none, md:hidden) that signals horizontal scroll is available (UX-01)
- Map legend updated from abbreviated labels ("Broken", "Crossing", "Lighting") to canonical labels matching translations.ts ("Damaged Footpath", "Unsafe Crossing", "Poor Lighting") (UX-03)
- ReportsMap.tsx local CATEGORY_LABELS map deleted; popup now uses getCategoryLabel() — one fewer place to maintain label strings
- All 27 ReportsTable tests pass with updated label expectations; Next.js build succeeds

## Files Created/Modified

- `frontend/app/admin/components/ReportsTable.tsx` - Added getCategoryLabel import; replaced raw category enum with getCategoryLabel().en in main table and sub-table; added overflow-x-auto relative wrapper with fade gradient div
- `frontend/app/admin/components/__tests__/ReportsTable.test.tsx` - Updated text assertions from raw enums ("broken_footpath") to human-readable labels ("Damaged Footpath", "Poor Lighting", "Unsafe Crossing")
- `frontend/app/map/page.tsx` - Added getCategoryLabel import; replaced hardcoded abbreviated legend array with key-based array using getCategoryLabel(key).en
- `frontend/app/components/ReportsMap.tsx` - Added getCategoryLabel import; deleted local CATEGORY_LABELS constant; replaced CATEGORY_LABELS lookup in popup with getCategoryLabel(report.category).en

## Decisions Made

- getCategoryLabel from translations.ts is the single source of truth for all category labels — this eliminates drift between three previously independent label surfaces (admin table, map legend, map popup)
- Scroll gradient uses `md:hidden` so desktop users see no visual change; only mobile/tablet users where the table overflows horizontally see the right-edge fade
