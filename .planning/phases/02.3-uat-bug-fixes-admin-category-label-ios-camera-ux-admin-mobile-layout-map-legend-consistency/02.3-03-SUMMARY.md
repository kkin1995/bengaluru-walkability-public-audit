# Phase 02.3 Plan 03: Admin Mobile Layout Summary

**One-liner:** Extracted admin sidebar into AdminSidebar.tsx client component with hamburger trigger, slide-in drawer on mobile, and static left nav on desktop, keeping all auth logic server-side in layout.tsx.

## What Was Built

UX-02 fix: The admin sidebar was previously a static `<nav>` embedded in the server-rendered `layout.tsx`. On mobile portrait, this nav occupied the full left column with no way to collapse it, making navigation unreachable on narrow screens.

The fix extracts the sidebar into `AdminSidebar.tsx` — a `'use client'` component that:
- On mobile (below `md` breakpoint): renders as a hidden slide-in drawer triggered by a fixed hamburger button
- On desktop (`md+`): renders as the same static left nav as before (no visual change)

`layout.tsx` remains a server component and retains all auth logic. It now passes `role` as a prop to `AdminSidebar`.
