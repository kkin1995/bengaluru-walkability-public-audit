## Decisions Made

- **COOKIE_SECURE default = true**: Production environments are HTTPS-only; the dev override makes the secure-by-default choice opt-out for local development rather than opt-in for production
- **script-src unsafe-inline accepted risk**: Next.js 14 App Router requires inline scripts at build time; full remediation needs per-request nonces propagated from Next.js middleware through nginx headers — tracked for post-launch
- **style-src unsafe-inline removed**: Safe to remove — Tailwind v3 generates a single static stylesheet at build time; no runtime inline style injection
- **npm audit --audit-level=high**: Low/moderate CVEs in the JS ecosystem are frequently noise (dev-only, non-exploitable paths); high/critical are genuine blockers
- **Empty audit.toml allowlist**: Provides a documented escape hatch for unresolvable CVEs without bypassing the check entirely; format documented in file comments
