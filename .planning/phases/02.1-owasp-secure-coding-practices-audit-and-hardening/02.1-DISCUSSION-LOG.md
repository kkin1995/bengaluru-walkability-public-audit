## CSP unsafe-inline Hardening

| Option | Description | Selected |
|--------|-------------|----------|
| Fix style-src; document script-src | Remove unsafe-inline from style-src (Tailwind static stylesheet — achievable). Document script-src unsafe-inline as accepted risk with nonce roadmap issue. | ✓ |
| Full nonce implementation | Per-request nonces in Next.js middleware + nginx header propagation. Fully closes the finding. | |
| Accept both as known risk | Document both with compensating controls. Zero code change. | |

**User's choice:** Fix style-src; document script-src
**Notes:** Nonce implementation is architecturally correct but non-trivial to validate nginx header propagation on a pre-launch timeline. App has no dangerouslySetInnerHTML, no user HTML rendered raw — script-src unsafe-inline risk is real but low-probability. Pragmatic split: fix what's achievable, document the rest with a tracked issue.
