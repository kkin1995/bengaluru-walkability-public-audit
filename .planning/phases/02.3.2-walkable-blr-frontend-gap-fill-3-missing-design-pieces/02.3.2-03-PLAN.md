**Piece 1 — Gallery escape hatch (home page):**
1. Open http://localhost:3000
2. Below the green "Report an issue" CTA, you should see a muted text-link with an image icon on the left and "or upload a saved photo" text (with subtle underline)
3. The link should be centered, visually subdued (not green/accent colored)
4. Gap above: approximately 14px from primary CTA bottom
5. Gap below: approximately 10px from the "No login · Takes 20 seconds · Anonymous" meta row
6. Tap/click the gallery link — on desktop it should open a file picker without pre-selecting camera; on iOS it should show the full picker sheet (Camera / Photo Library / Files) rather than jumping directly to camera

**Piece 2 — CategoryGrid 2-col × 3-row (report flow):**
1. On home page, tap the primary green CTA and select any photo
2. You should land on /report and see the category selection step
3. The chip grid should show 2 columns × 3 rows (6 chips total: No path, Damaged, Blocked, Crossing, Lighting, Other)
4. Each chip should be visibly taller (~96px min height) than before
5. At the bottom of the chip grid, a shield icon + "Photos are stripped of private metadata before upload" text should be visible in muted color

**Piece 3 — Home page live count:**
1. On http://localhost:3000, check the map preview area
2. A pill showing "{N} reports" (where N is the total count from the API) should be visible in the bottom-left of the map preview
3. If the backend is not running, the pill may be absent — this is the correct fallback behavior

**Piece 4 + 5 — Map chip strip with counts:**
1. Open http://localhost:3000/map
2. Below the top overlay bar (back arrow + Bengaluru search bar + filter button), a row of 7 chips should be visible: All, Damaged, Blocked, No path, Crossing, Lighting, Other
3. Each chip should show a count suffix once reports load: "All · N", "Damaged · N", etc.
4. Before reports load, chips should show label only with no count suffix
5. Tap "Damaged" — only orange/damaged pins should remain on the map; others disappear
6. Tap "All" — all pins restore
7. Chip strip should scroll horizontally if it overflows the viewport width, with no visible scrollbar
