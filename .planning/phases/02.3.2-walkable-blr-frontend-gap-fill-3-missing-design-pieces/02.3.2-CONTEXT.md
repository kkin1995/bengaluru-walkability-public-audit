**Admin pages and backend are OUT OF SCOPE.** This is frontend-only on a new branch from `main`.

<decisions>
## Implementation Decisions

### Branch Strategy
- **D-01:** Create a new branch from `main` with an appropriate name (e.g. `feat/02.3.2-frontend-gap-fill`). Do NOT commit to `main`. The `ui-redesign` branch has already been merged and deleted.

### Piece 1: Home Screen — Gallery Escape Hatch (Frame 01)
- **D-02:** Keep the primary green CTA (`<ReportCTA />`) exactly as-is. Its hidden `<input type="file" accept="image/*" capture="environment">` stays unchanged.
- **D-03:** Directly below the primary CTA (14px gap), add a **centered text-link button**. Layout: `inline-flex`, `gap: 8px`, `padding: 8px 12px`, transparent background, no border.
  - Left: `<Icon name="image" size={16} />` in `var(--muted)`.
  - Right: bilingual text via `<Bi en="or upload a saved photo" kn="ಉಳಿಸಿದ ಫೋಟೋ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ" />`. The EN and KN text words each have a `1px` bottom border in `var(--border-strong)` — a subtle underline, not a full-width link underline.
  - Color: `var(--muted)` — NOT accent. Must not compete with the primary CTA.
  - Font size: `13px`.
- **D-04:** Wire the gallery link to a **separate hidden `<input type="file" accept="image/*">`** with **no `capture` attribute**. This causes iOS/Android to show the full picker sheet (Camera / Photo Library / Files). The primary CTA input keeps `capture="environment"`. Two distinct inputs, two distinct refs.
- **D-05:** Spacing: `14px` gap between primary CTA bottom and gallery link top; `10px` gap between gallery link bottom and the "No login · Takes 20 seconds · Anonymous" meta row.
- **D-06:** After photo selection via either entry point, the flow converges: selected photo → `photo-store` singleton → Category screen with photo thumbnail filled in. The existing `ReportCTA` photo-handling pipeline (exifr extraction, compression, `storePendingPhoto`, `router.push("/report")`) is the template. The gallery link must replicate this same pipeline on its own ref/handler.
- **D-07:** The gallery link is implemented in `ReportCTA.tsx` (the existing client component), not as a new component. Add the second `useRef`, the second `<input>`, and the shared handler there.

### Piece 2: Category Screen — 3×2 Grid + Privacy Line (Frame 02)
- **D-08:** Change `CategoryGrid.tsx` grid from **2 columns → 3 columns**: `gridTemplateColumns: "1fr 1fr 1fr"`. Gap tightens from `10px` → `8px`.
- **D-09:** Each chip in the new 3-column grid:
  - `padding: 14px 10px` (reduced horizontal padding from 12px/16px — narrower column)
  - `minHeight: 96px` (reduced from 108px)
  - Icon: `24px` (reduced from 26px)
  - Bilingual label: EN at `13px font-weight 600`, KN at `11px`. Same `<Bi>` pattern. Allow up to 2 lines for EN if the label wraps at this narrower width; KN stays single line.
  - Active state unchanged: ink fill (`background: var(--ink); color: #fafaf9`), check badge at `18px` top-right.
- **D-10:** Below the chip grid, with `marginTop: 16px`, add a **privacy/EXIF notice row**:
  - `<Icon name="shield" size={14} style={{ color: "var(--muted)", flexShrink: 0 }} />`
  - Text: `"Photos are stripped of private metadata before upload"`
  - Container: `display: flex; alignItems: center; gap: 8px; fontSize: 12px; color: var(--muted)`
  - The shield icon must have `flexShrink: 0` so it never collapses on narrow screens.
- **D-11:** The sticky "Continue" button at the bottom of the Category screen stays unchanged.

### Piece 3: Home Page Live Count
- **D-12:** Already done on `main`. `frontend/app/page.tsx` is an async server component that calls `fetchReportTotal()` with `next: { revalidate: 60 }`. Verify and confirm — no code change expected.

### Piece 4: Map Filter Chip Strip
- **D-13:** The chip strip is **always visible** just below the top overlay bar on `/map`. It does NOT toggle on/off — chips are permanently shown.
- **D-14:** The chip strip is **horizontally scrollable** with no visible scrollbar (`.no-scrollbar` CSS class already in `globals.css`).
- **D-15:** **7 chips**: "All" (default selected) + 6 category chips — "Damaged", "Blocked", "No path", "Crossing", "Lighting", "Other". Short design labels only (not the full "Damaged Footpath" from `translations.ts`).
- **D-16:** **Filtering behavior**: selecting a category chip hides all other category pins on the map (completely absent — not faded). "All" restores all pins.
- **D-17:** **Active chip state**: `background: var(--ink); color: #fafaf9`. Inactive chips: `background: rgba(255,255,255,0.95); border: 1px solid var(--border); backdrop-filter: blur(8px)`.

### Piece 5: Per-Category Counts on Chips
- **D-18:** Counts are **derived from the fetched reports array** — zero extra API calls.
- **D-19:** `ReportsMap.tsx` gets a new optional `onReportsLoaded?: (reports: Report[]) => void` callback prop. When the fetch completes, it calls this with the full unfiltered array. `map/page.tsx` stores the array and computes per-category counts client-side with a single `.reduce()`.
- **D-20:** `ReportsMap.tsx` gets a new optional `categoryFilter?: string` prop. When set to a category enum value, only CircleMarkers for that category render. When `undefined` or `"all"`, all markers render.

### Claude's Discretion
- Exact branch name (must start with `feat/02.3.2-`)
- How to style the underline on gallery link text (CSS `textDecoration` vs `borderBottom` — either is fine as long as it's subtle)
- Whether the Bengaluru pill in the top bar shows a total count alongside the city name
- Minimum chip width behavior on very small screens
- Test strategy for the new ReportsMap props, chip strip, and gallery escape hatch

</decisions>

## Existing Code Insights

### Reusable Assets
- `ReportCTA.tsx` — already a `"use client"` component with one `useRef<HTMLInputElement>(null)`, exifr extraction, compress loop, `storePendingPhoto`, and `router.push("/report")`. The gallery input adds a second `useRef` and the same handler pipeline triggered by `type="file"` with no `capture`.
- `photo-store.ts` — `storePendingPhoto(PendingPhoto)` / `consumePendingPhoto()` singleton. Both the camera and gallery paths must call `storePendingPhoto` before navigating so `/report` receives the photo on mount.
- `.no-scrollbar` — in `globals.css`, applies `scrollbar-width: none` + `::-webkit-scrollbar { display: none }`. Ready to use on chip strip container.
- `.press` — in `globals.css`, tap feedback. Use on each chip and on the gallery link button.
- `Icon` primitive — `image` icon (rectangle + sun + mountain) and `shield` icon already exist in `Icon.tsx` based on the icon names list in 02.3.1-CONTEXT.md.
- `Bi` primitive — stacked EN/KN text. Use for gallery link bilingual label.

### Established Patterns
- `map/page.tsx` is already `"use client"` — no boundary change needed for chip strip state.
- `ReportsMap.tsx` `fetchReports` inside `useCallback` + `useEffect` — call `onReportsLoaded(data)` after `setReports(data)` in the fetch callback.
- Category grid chips in `CategoryGrid.tsx` — currently `gridTemplateColumns: "1fr 1fr"`, `gap: 10px`. Change to `"1fr 1fr 1fr"`, `gap: 8px`.

### Integration Points
- `page.tsx` home page: insert gallery link JSX between the `<ReportCTA />` render and the meta row. The `<ReportCTA>` component itself handles the second input — `page.tsx` only adjusts the spacing wrapper.
- `CategoryGrid.tsx`: self-contained component change — no parent changes needed.
- `map/page.tsx → ReportsMap`: two new optional props (`categoryFilter`, `onReportsLoaded`). Existing `apiUrl` prop unchanged.
- Count derivation in `map/page.tsx`: `const counts = allReports.reduce((acc, r) => { acc[r.category] = (acc[r.category] ?? 0) + 1; return acc; }, {} as Record<string, number>)`.
