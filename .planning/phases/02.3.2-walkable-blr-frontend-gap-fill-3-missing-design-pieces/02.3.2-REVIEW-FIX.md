### WR-01: Object URL leaked when image compression fails

**Files modified:** `frontend/app/components/ReportCTA.tsx`

### WR-02: Same-file re-selection silently fails after an error

**Files modified:** `frontend/app/components/ReportCTA.tsx`
**Commit:** 3870c3a
**Applied fix:** Added `e.target.value = ""` immediately after the `if (!file) return` guard in both `handleChange` (line 48) and `handleGalleryChange` (line 113). Clearing the input value before processing ensures the browser fires `onChange` even when the same file is selected again.
