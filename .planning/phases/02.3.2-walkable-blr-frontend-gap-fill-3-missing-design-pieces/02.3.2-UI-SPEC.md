## Typography

**Scale: 4 sizes, 2 weights.**

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Heading | 28px | 600 | 1.2 | Inter (`--font-sans`) | `h1` "Fix the footpath." on home page — size alone provides visual dominance |
| Body | 16px | 400 | 1.5 | Inter | Paragraph text on home and report pages |
| Label | 14px | 400 | 1.5 | Inter | Map overlay text, meta row, chip count format |
| Caption | 13px | 600 (EN) / 400 (KN) | 1.15 | Inter + Noto Sans Kannada | Category chip labels (EN bold over KN); gallery link text; filter chip labels; privacy notice; SectionLabel (mono uppercase); Pill text |

**Weights: 400 (regular) and 600 (semibold) only.**

- Weight 500 eliminated: filter chips and meta row use **600** instead.
- Weight 700 eliminated: `h1` at 28px uses **600** — size dominance alone is sufficient.

Component-level size notes (not additional scale entries — all resolve to 13px Caption):

| Component | Resolved size | Note |
|-----------|--------------|-------|
| SectionLabel | 13px | Mono uppercase via `font-family: var(--font-mono); text-transform: uppercase` — same intent as 11px legacy, bumped to Caption scale |
| Privacy notice | 13px | `color: var(--muted)` — bumped from 12px to Caption scale |
| Pill / `Pill.tsx` | 13px | Glass pill on map preview — bumped from 12px to Caption scale |

KN text: always `font-family: var(--font-kn)` via `.bi-kn` class. KN size = `0.72em` of EN size (resolved via `.bi-kn` in `globals.css`). KN opacity = 0.7. KN weight = 400 always.

## Color

All values are CSS custom properties from `globals.css` (source: codebase scan).

| Role | Token | Resolved Value | Usage |
|------|-------|----------------|-------|
| Dominant (60%) | `--bg` | `#fafaf9` | Page background, `<main>` surface |
| Secondary (30%) | `--surface` | `#ffffff` | Cards, inactive chip background (with opacity), overlay bars |
| Accent (10%) | `--accent` | `oklch(0.62 0.14 145)` | Reserved list below |
| Destructive | `--danger` | `oklch(0.62 0.14 30)` | Not used in this phase |

**Accent (`--accent`) is reserved for:**
- Primary CTA `<ReportCTA />` button background (variant `accent`)
- Floating "Report here" Btn on map page (variant `accent`)
- Map pin icon (`var(--accent)`) in the top overlay search bar

**Accent is NOT used for:**
- Gallery escape hatch link — uses `var(--muted)` (`#78716c`)
- Map filter chips — inactive chips use white/glass; active chip uses `var(--ink)` (dark), not accent
- Privacy notice row — uses `var(--muted)`

Supporting tokens used in this phase:

| Token | Value | Usage |
|-------|-------|-------|
| `--ink` | `#1c1917` | Active chip fill, primary text, active filter chip bg |
| `--ink-2` | `#44403c` | Inactive chip text on map, body secondary |
| `--muted` | `#78716c` | Gallery link text + icon; privacy notice text + icon |
| `--muted-2` | `#a8a29e` | Sub-labels |
| `--border` | `#e7e5e4` | Category chip inactive border; filter chip border |
| `--border-strong` | `#d6d3d1` | Gallery link text underline (1px borderBottom) |
| `--surface-2` | `#f5f5f4` | — not used in this phase directly |

Active chip color contract (shared, both CategoryGrid chips and map filter chips):
- `background: var(--ink)` — `#1c1917`
- `color: #fafaf9`
- `border: none` (map chips) or `1.5px solid var(--ink)` (category chips)

Inactive map filter chip:
- `background: rgba(255,255,255,0.9)`
- `border: 1px solid var(--border)`
- `color: var(--ink-2)`
- `backdropFilter: blur(8px)`
- `boxShadow: var(--shadow-sm)`

4. `compressImage()` if over 10MB
5. `storePendingPhoto({ file, previewUrl, lat, lng, locationSource, gpsConfirmed, photoTime })`
6. `router.push("/report")`

### Piece 4 — Map Filter Chip Strip (Frame 05)

**Modified file:** `frontend/app/map/page.tsx`

New state:

| State | Type | Initial |
|-------|------|---------|
| `activeFilter` | `string` | `"all"` |
| `allReports` | `Report[]` | `[]` |

Chip strip container:

| Property | Value |
|----------|-------|
| `position` | `absolute` |
| `top` | `76px` |
| `left` | `0` |
| `right` | `0` |
| `zIndex` | `500` |
| `padding` | `0 16px` |
| `overflowX` | `auto` |
| `className` | `"no-scrollbar"` |
| Inner layout | `display: flex; gap: 8px; paddingBottom: 4px` (to prevent shadow clip) |

Chip definition table (7 chips):

| Order | Label stem | Category enum value |
|-------|------------|---------------------|
| 1 | All | `"all"` |
| 2 | Damaged | `broken_footpath` |
| 3 | Blocked | `blocked_footpath` |
| 4 | No path | `no_footpath` |
| 5 | Crossing | `unsafe_crossing` |
| 6 | Lighting | `poor_lighting` |
| 7 | Other | `other` |

Chip count format: `"Damaged · 38"` — label + ` · ` + count (middle-dot U+00B7 as separator). When count is 0, still show `"Damaged · 0"`. "All" chip shows total: `"All · N"`.

Each chip element:

| Property | Value |
|----------|-------|
| `height` | `36px` |
| `padding` | `0 14px` |
| `borderRadius` | `var(--r-full)` |
| `whiteSpace` | `nowrap` |
| `fontSize` | `13px` |
| `fontWeight` | `600` |
| `className` | `"press"` |
| Active bg | `var(--ink)` |
| Active color | `#fafaf9` |
| Active border | `none` |
| Inactive bg | `rgba(255,255,255,0.9)` |
| Inactive border | `1px solid var(--border)` |
| Inactive color | `var(--ink-2)` |
| Inactive backdropFilter | `blur(8px)` |
| Inactive boxShadow | `var(--shadow-sm)` |

Filtering behavior:
- Selecting a category chip sets `activeFilter` to that enum value
- Tapping the active chip again does NOT deselect — "All" chip is the only way back to all
- Selecting "All" sets `activeFilter` to `"all"`
- `activeFilter` is passed as `categoryFilter` prop to `<ReportsMap />`
- When `categoryFilter` is `"all"` or `undefined`, all markers render
- When `categoryFilter` is a category enum, only markers for that category render (completely hidden — not faded)

### Piece 5 — Per-Category Counts on Chips

**Modified file:** `frontend/app/components/ReportsMap.tsx`

New props (both optional, backward-compatible):

| Prop | Type | Description |
|------|------|-------------|
| `categoryFilter?: string` | `string \| undefined` | When set to a category enum value, only CircleMarkers of that category render |
| `onReportsLoaded?: (reports: Report[]) => void` | callback | Called after `setReports(data)` in the fetch completion handler |

Count derivation in `map/page.tsx` (passed from `onReportsLoaded` callback):

```
const counts = allReports.reduce(
  (acc, r) => { acc[r.category] = (acc[r.category] ?? 0) + 1; return acc; },
  {} as Record<string, number>
);
const total = allReports.length;
```

Zero extra API calls. Counts update once after the initial fetch completes.
