## Data Backup Strategy

| Option | Description | Selected |
|--------|-------------|----------|
| Cloudflare R2 | Free 10 GB egress; same provider as tunnel | |
| Backblaze B2 | Free 10 GB; popular backup target | |
| External/local drive | Co-located; single point of failure for disaster | |
| Separate HDD (sda /data) | Physically separate drive, no cloud dependency | ✓ |

**User's choice:** Backup to `/data` on `sda` (separate HDD, named Docker volumes). `pg_dump` for postgres, temporary Alpine container `rsync` for uploads volume. Weekly systemd timer, 30-day retention, restore procedure in DEPLOYMENT.md. No cloud dependency.

**User's choice:** Shell script + systemd timer
