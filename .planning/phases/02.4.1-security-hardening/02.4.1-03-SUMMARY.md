## Decisions Made
- `alpine tar czf` used for uploads volume backup instead of rsync — alpine base image does not ship rsync (would require `apk add rsync` adding network dependency per run). `tar czf` produces byte-for-byte faithful archive and matches the §11 restore flow. No information lost vs rsync approach.
- `docker exec` used for pg_dump instead of `docker run --network` — avoids auto-generated Compose network name ambiguity (RESEARCH Pitfall 3).
- `Persistent=true` on timer — catches missed weekly runs after host reboot without operator intervention.
- UptimeRobot chosen for uptime monitoring — free tier, HTTP/s keyword monitor, 5-minute interval, no paid plan required.
