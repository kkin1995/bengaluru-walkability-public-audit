## Decisions Made

- **JPEG guard placement before strip_exif:** `img-parts` silently returns original bytes on parse failure, so a non-JPEG file would be written to disk if the check came after EXIF stripping (RESEARCH Pitfall 1)
- **Pre-existing clippy errors fixed:** `cargo clippy --all-targets -- -D warnings` is the acceptance criterion; errors in `queries.rs` and `models/report.rs` were pre-existing but blocking the gate — fixed as Rule 1 (auto-fix bugs)
- **Logout uses `mut removal` pattern:** `Cookie::build().same_site().build()` produces a `Cookie`; `set_secure(true)` is called conditionally as a setter, exactly mirroring the `admin_login` pattern at lines 315-328
