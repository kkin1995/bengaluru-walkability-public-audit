## Decisions Made

- **Standalone document at repo root:** STAGING-SETUP.md lives at `./STAGING-SETUP.md` rather than inside `.planning/`. Future contributors and partners can find it without knowing the planning directory structure.
- **PostGIS template warning is prominent:** Standard Railway Postgres lacks PostGIS library files on disk — `CREATE EXTENSION postgis` fails. This is called out explicitly in Step 1 with the exact error message to look for.
- **Deployment ordering before env vars:** The ordering constraint (Railway-first) is the highest-risk misconfiguration and is placed before the env var checklist so readers cannot miss it.
- **Ephemeral uploads documented, not fixed:** Railway filesystem is reset on redeploy. This is acceptable for UAT per D-03. The Known Limitations section flags this for production planning.
