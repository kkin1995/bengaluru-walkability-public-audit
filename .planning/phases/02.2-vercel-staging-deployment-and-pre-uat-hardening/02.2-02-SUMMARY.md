## Decisions Made

- **Graceful secret gate:** `if: ${{ secrets.RAILWAY_BACKEND_URL != '' }}` — smoke-test job skips (rather than fails) when RAILWAY_BACKEND_URL secret is not yet set. This prevents CI breakage during initial Railway provisioning and in forks.
- **30s initial delay before retry loop:** Railway deploys asynchronously from GitHub Actions push events. Without a delay, the first health check attempt would race the deploy startup.
- **dockerfilePath = "Dockerfile" (relative):** When Railway's service Root Directory is set to `backend/`, the `dockerfilePath` in railway.toml is relative to that root — so `Dockerfile` not `backend/Dockerfile`.
- **healthcheckTimeout = 300:** Rust Docker builds are slow on first deploy before layer cache is warm. 5 minutes accommodates cold-start without marking the container unhealthy prematurely.
