## Backend Hosting Platform

| Option | Description | Selected |
|--------|-------------|----------|
| Hetzner/DigitalOcean VPS | Reuse docker-compose.yml exactly; PostGIS works as-is; ~€4-6/mo; highest staging/production parity; SSH deploy step needed | |
| Railway | Managed PostGIS template; Dockerfile auto-detected; $5/mo with $5 credit; re-express compose networking as Railway DNS | ✓ |
| Render (paid tier) | Docker + PostGIS via CREATE EXTENSION; $7/mo to avoid cold-start; less polished multi-service story | |
| Fly.io | Docker + PostGIS flag; scales to zero; Managed Postgres Basic = $38/mo (budget risk) | |

**User's choice:** Railway — "can we use something that is free like Railway for the Backend"
**Notes:** User explicitly wanted a free/low-cost option. Railway's $5/mo credit covers a Rust binary + Postgres at zero traffic. Vercel handles the frontend.

## Deployment Automation

| Option | Description | Selected |
|--------|-------------|----------|
| CI-gated push to main + workflow_dispatch | Current deploy.yml shape (needs: ci) + dispatch trigger; auto + deliberate promote | ✓ |
| Manual workflow_dispatch only | Maximum control; friction for solo dev; explicit trigger required | |

**User's choice:** CI-gated push to main + workflow_dispatch (accepted recommended option)
**Notes:** Both Railway and Vercel auto-deploy on push via GitHub integration. deploy.yml becomes primarily a CI gate + post-deploy smoke test orchestrator.

## Pre-UAT Hardening Scope

| Item | Description | Selected |
|------|-------------|----------|
| Staging smoke tests in CI | deploy.yml hits /health + /api/reports after deploy; fails workflow if staging is down | ✓ |
| Env var / secrets checklist | Documented list of required Railway + Vercel env vars to verify before sharing UAT link | ✓ |

**Notes:** User wants a complete pre-UAT checklist. Smoke tests are automated; admin verification is a manual gate.
