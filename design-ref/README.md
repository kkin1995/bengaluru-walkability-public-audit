# Walkable BLR — Design Source Files

These are the canonical JSX/CSS sources for the Phase 02.3.1 UI redesign.
Originally exported from claude.ai/design as `Walkable BLR Redesign.html`.

Files preserved here because the original lived under `/tmp/` which is ephemeral.

- `styles.css` — full CSS variable system (the design system)
- `primitives.jsx` — Bi, Icon, Btn, Pill, SectionLabel source + all 32 icon SVG paths
- `screens-capture.jsx` — HomeScreen + CaptureScreen prototype
- `screen-category.jsx` — CategoryScreen prototype (Step 1 of 2)
- `screens-confirm.jsx` — ConfirmScreen + SuccessScreen + MapScreen prototypes

The Next.js implementation lives under `frontend/app/` — these files are reference only.
